# Release B (AGENTS.md consolidation) Implementation Plan

> **For agentic workers:** executed natively in one session (owner: "do not stop"). Steps use checkbox syntax.

**Goal:** Lossless, validated consolidation of legacy `CLAUDE.md`/`GEMINI.md`/`QWEN.md` into `AGENTS.md`, safe apply/delete/commit/rollback, automated private Claude-rule move with two human checkpoints, and an update-time proposal.

**Architecture:** One deterministic helper `scripts/migrate.py` (plan → check → apply → commit/rollback, plus `private` state machine) built on the release-A audit (`scripts/instructions.py`) and the single Bash parser (`hooks/lib/discover.sh`). The agent edits proposed outputs and coverage decisions in the plan JSON; the helper never calls an LLM. Optimization stays in lint #11; the helper only enforces critical-rule, portability and budget gates.

**Tech Stack:** Python 3 stdlib, Bash, Git CLI, unittest.

**Spec:** epic #6 r3 §5 (B1–B6, §6), sub-issues #10–#14 (final text after the decomposition review).

## Global Constraints

- Wiki schema stays `4.0`; behavior version → `4.12.0`. No Claude version check or gate.
- Supported CLIs: Claude Code, Codex, Qwen Code, agy CLI; plus ChatGPT/GitHub adapter. No Gemini CLI.
- Same-level different valid wiki pointers → blocked; root/nested split is not a conflict.
- Fast paths only for provable byte cases in the same logical scope; semantic rewrite proves accounting, not equivalence.
- Budgets: agy 24 000 bytes per rule file; Codex 32 KiB per root→cwd chain (configured value if known). Bytes ≠ tokens.
- Never: `git reset --hard`, `git clean`, broad glob delete, writing through a symlink, deleting a resolved target instead of a literal link, committing private files, publishing private text.
- Backups only under `$(git rev-parse --absolute-git-dir)/wiki-migration/<id>/` (0700 dir, 0600 files).
- Private flow: two checkpoints recorded explicitly; no automatic global `claude-md-and-agents-md`.

## Review Focus

1. A legacy pointer to a custom wiki must survive consolidation (future-tree discovery equals initial selection).
2. `AGENTS.md → CLAUDE.md` alias must be materialized before the target is deleted; `CLAUDE.md → AGENTS.md` deletes only the link.
3. A critical line (MUST/NEVER/ЗАБОРОНЕНО/ОБОВ’ЯЗКОВО…) silently dropped by an agent rewrite must fail `check`.
4. Unrelated staged/dirty user paths survive `apply` + `commit` + `rollback` unchanged.
5. A plan computed before a concurrent edit must not apply (stale hash → stop).

## Tasks

### Task 1: Fragments and classification (#10)
**Interfaces — Produces:** `fragments(path: Path, text: str, scope: str) -> list[dict]` (keys `id, source, scope, kind ∈ {frontmatter, preamble, h1, section, pointer}, start, end, heading, text, sha256, critical`); `build_plan(root: Path, cwds: list[Path]) -> dict` (schema 1, `status ∈ {ready, needs-decision, blocked}`).
- [ ] Tests: identical copies; rules-in-CLAUDE + stubs; same headings/different bodies; same bytes in different scopes; stub with extra text; file without H2 + frontmatter + fences + repeated headings fully covered; canonical-only no-op; same-level wiki conflict → blocked; aliases classified as aliases.
- [ ] Implement fence-aware splitting, alias groups (same physical file), stub template recognition, contained-exact, draft output = canonical + unique fragments in source order + generated relative `## Wiki` when needed.

### Task 2: Check (#10/#11)
**Produces:** `check(plan: dict, root: Path, snapshot: bool=False) -> dict` (`errors`, `warnings`, `decisions_needed`, `ok`).
- [ ] Tests: missing coverage; stale source hash; placed text absent in destination; critical line dropped; pointer resolves elsewhere / absent with custom wiki; absolute pointer rewritten relative; over-budget agy file and Codex chain; Claude `@path` include finding; invalid agy `trigger`; snapshot mode without Git base.
- [ ] Implement future-tree discovery in a temp Git repo mirroring instruction files and wiki `index.md` locations.

### Task 3: Apply, commit, rollback (#12)
**Produces:** `apply(plan, root, write: bool) -> dict`, `commit(migration_id, root, message) -> dict`, `rollback(migration_id, root, write) -> dict`; state in `<git-dir>/wiki-migration/<id>/state.json`.
- [ ] Tests: new AGENTS; existing untracked AGENTS backed up; dirty source backed up; unrelated staged path preserved through commit; commit contains only public manifest; alias materialize/unlink; discovery after apply; rollback restores tracked (from base) and untracked (from backup) and removes new outputs only when hashes match; concurrent edit → stop.

### Task 4: Private flow (#13)
**Produces:** `private_prepare`, `private_confirm(checkpoint: 1|2)`, `private_switch`, `private_recover`, `private_status`.
- [ ] Tests: switch before checkpoint 1 refused; completed only after checkpoint 2; exclude in common `info/exclude`, `git check-ignore` true, not in index; tracked private destination → stop; relative `@import` recomputed; recover restores original; public plan never deletes `CLAUDE.local.md`.

### Task 5: Workflow, remote, docs, bundle, version (#11/#14)
- [ ] References/README/SKILL routing; lint #11 skippable step text; update/init proposal text; GitHub remote delete only after executed validator (`migrate.py check --snapshot`), else `coverage not machine-validated`.
- [ ] Bundle via `build_skill.py`; contract guards; version 4.12.0; history entry; validation doc.
